🎯 ThreeCanvas.tsx — 3D Renderer

onContextCreate: Initializes scene, camera, renderer, lighting (ambient + directional)
ModelLoader.loadMuscleModel('body'): Tries to load body.glb, falls back to placeholder cube
PanResponder (deprecated ⚠️): rotateCamera, panCamera, zoomCamera via gestures
render loop: requestAnimationFrame with cube rotation + renderer.render()
Cleanup: cancelAnimationFrame + renderer.dispose() on unmount ✅
✅ Fixed: Removed onTouchMove={undefined} — touch now enabled on 3D canvas
⚠️ PanResponder deprecated — use react-native-gesture-handler
⚠️ No raycasting integration — touch rotates camera but doesn't select muscles
⚠️ ModelLoader instantiated outside hook — potential memory leak
